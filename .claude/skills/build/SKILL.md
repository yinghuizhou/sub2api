创建产品团队，完整开发一个新功能。

## 团队成员
- Product Manager - 协调整体流程
- Competitor Analyst - 市场分析
- Requirements Analyst - 需求文档
- UI/UX Designer - 界面设计
- Frontend Developer - 前端实现
- Backend Developer - 后端实现
- QA Engineer - 测试验证
- DevOps Engineer - 部署上线

## 开发流程

### Phase 1: 分析阶段
1. **Competitor Analyst**: 竞品分析
   - 分析市场现有解决方案
   - 识别差异化机会

2. **Requirements Analyst**: 需求分析
   - 编写PRD文档
   - 定义用户故事
   - 制定验收标准

3. **Product Manager**: 需求评审

### Phase 2: 设计阶段
4. **UI/UX Designer**: 界面设计
5. **Product Manager**: 设计评审

### Phase 3: 开发阶段
6. **Backend Developer**: 后端开发
7. **Frontend Developer**: 前端开发
8. **Code Review**: 运行 `/code-review` 检查代码质量

### Phase 4: 测试阶段
9. **QA Engineer**: 测试验证

### Phase 5: 部署阶段
10. **DevOps Engineer**: 部署上线
11. **Product Manager**: 上线总结
