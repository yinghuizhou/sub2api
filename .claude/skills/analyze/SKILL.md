name: analyze
description: 执行竞品分析，研究市场趋势和竞争对手
---

请 competitor-analyst 执行竞品分析：

1. 确认分析目标（具体功能/产品/市场趋势）
2. 识别主要竞品
3. 收集竞品信息（使用WebSearch和WebFetch）
4. 分析对比（功能、性能、用户体验、定价）
5. 识别差异化机会
6. 生成分析报告

分析维度：
- 功能特性对比
- 技术实现方式
- 用户体验评价
- 定价策略
- 市场定位
- 优势与劣势

输出物：
- 竞品分析报告（docs/competitor-analysis/）
- 功能对比矩阵
- SWOT分析
- 战略建议

主要竞品参考：
- Google Translate
- DeepL
- Microsoft Translator
- 有道翻译
- 腾讯翻译君
- 百度翻译
