---
name: design
description: UI/UX设计，包括用户流程、界面原型和设计规范
---

请 ui-ux-designer 执行设计任务：

1. 确认设计目标（新功能/改版/优化）
2. 分析用户需求和使用场景
3. 设计用户流程
4. 创建界面原型（ASCII wireframe）
5. 定义交互规范
6. 输出设计文档

设计流程：
1. 需求理解
   - 功能目标
   - 目标用户
   - 使用场景

2. 用户体验设计
   - 用户旅程地图
   - 信息架构
   - 交互流程

3. 界面设计
   - 页面布局
   - 组件设计
   - 视觉风格

4. 设计规范
   - 颜色方案
   - 字体规范
   - 间距规范
   - 组件库

输出物：
- 线框图（ASCII Art）
- 交互流程图
- 设计规范文档（docs/design/）
- 组件设计说明

技术约束：
- 使用 Tailwind CSS
- 响应式设计（移动端优先）
- 无障碍访问（WCAG 2.1）
- 支持暗色模式
