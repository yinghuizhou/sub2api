# 管理员操作指南

本指南面向 Sub2API 平台的管理员，介绍如何管理用户、账户、分组、订阅、代理、系统配置以及运维监控。

---

## 管理员仪表板

访问 `/admin/dashboard` 查看全局运营状态：

- **统计概览**：总用户数、API Key 数、账户数、今日请求数
- **实时指标**：当前 RPM（每分钟请求数）、TPM（每分钟 Token 数）
- **使用趋势**：过去 7/30 天的使用量趋势
- **模型分布**：各 AI 模型的使用占比

---

## 用户管理

访问 `/admin/users`

### 用户列表

支持按邮箱搜索、按状态筛选（活跃/暂停）。

### 创建用户

适用于内部分配或批量创建用户场景：

1. 点击"创建用户"
2. 填写：邮箱、密码、角色（普通用户/管理员）、初始余额
3. 可选：设置并发限制、分配允许的分组

### 编辑用户

可修改：
- 基本信息（邮箱、角色）
- 账户状态（活跃/暂停）
- 并发限制
- 允许访问的分组

### 余额管理

点击用户行的"余额"按钮：
- **增加余额**：输入正数金额，填写操作备注
- **扣除余额**：输入负数金额（或选择"扣除"操作）
- **设置余额**：直接设定余额值

余额历史记录可在用户详情中的"余额历史"标签查看。

### 批量创建用户

通过导入功能批量创建，支持 CSV 格式（邮箱、密码、余额）。

## 分组管理

访问 `/admin/groups`

分组是 Sub2API 的核心概念，决定了用户可以使用哪些 AI 账户池以及计费倍率。

### 创建分组

| 字段 | 说明 |
|------|------|
| **名称** | 分组显示名称（唯一）|
| **平台** | 支持的 AI 平台：`claude` / `gemini` / `openai` / `antigravity` |
| **订阅类型** | 自定义标识符（用于匹配哪种订阅可以访问此分组）|
| **计费倍率** | 默认 1.0，设为 1.5 则向用户收取 1.5 倍的实际费用 |
| **是否专属** | 开启后只有订阅了此分组的用户才能使用 |
| **日/周/月限额** | 分组整体的用量上限（不是单用户限额）|

### 用量限制

为分组设置限额后，当分组整体达到限额时，新请求将被拒绝（等待下一个时间窗口重置）：
- 日限额：每天 00:00 重置
- 周限额：每周一 00:00 重置
- 月限额：每月 1 日 00:00 重置

### 模型路由

开启"模型路由"后，可以将特定模型的请求路由到指定的账户 ID 列表：

```json
{
  "claude-opus-4-5-20250929": [1, 2, 3],
  "claude-sonnet-4-5-20250929": [4, 5]
}
```

这样，请求 Opus 模型时只会使用 ID 为 1、2、3 的账户，请求 Sonnet 时只用 4、5。

### 图片生成费率

对于支持图片生成的平台（Antigravity、Gemini），可以设置：
- `image_price_1k`：1024×1024 分辨率每张价格（USD）
- `image_price_2k`：2048×2048 分辨率每张价格（USD）
- `image_price_4k`：4096×4096 分辨率每张价格（USD）

### 分组排序

拖拽分组列表项可以调整显示顺序，影响用户选择分组时的展示顺序。

## 账户管理

访问 `/admin/accounts`

账户是与 AI 平台对接的实际凭证（OAuth Token 或 API Key），是系统的核心资源。

### 账户类型

| 平台 | 支持的认证类型 | 说明 |
|------|---------------|------|
| Claude (Anthropic) | `oauth` | Claude.ai 账户通过 OAuth 授权 |
| Gemini (Google) | `oauth` | Google 账户通过 OAuth 授权 |
| OpenAI | `oauth` / `api_key` | OpenAI OAuth 或 API Key |
| Antigravity | `oauth` | 专属平台的 OAuth |

### 添加账户

#### 方式一：OAuth 授权（Claude/Gemini/OpenAI）

1. 点击对应平台的"添加账户"
2. 选择 OAuth 类型，点击"开始 OAuth 授权"
3. 在弹出窗口中完成 OAuth 登录
4. 系统自动获取 Access Token 和 Refresh Token
5. 设置并发数、优先级等参数
6. 分配到对应分组

#### 方式二：批量导入

点击"导入数据"，上传包含账户信息的 JSON 文件：

```json
[
  {
    "name": "账户 1",
    "platform": "claude",
    "type": "oauth",
    "credentials": {
      "access_token": "xxx",
      "refresh_token": "xxx"
    },
    "concurrency": 3,
    "priority": 1,
    "group_ids": [1]
  }
]
```

#### 方式三：从 CRS 同步

支持从 CRS（Claude Resource Server）同步账户，点击"从 CRS 同步"并粘贴同步链接。

### 账户状态

| 状态 | 说明 |
|------|------|
| `active` | 正常可用 |
| `disabled` | 手动禁用 |
| `suspended` | 系统自动暂停（账户过期等）|

调度器只选 `active` 且 `schedulable=true` 且未处于速率限制期的账户。

### 账户调度参数

| 参数 | 说明 |
|------|------|
| **并发数** | 该账户允许同时处理的最大请求数（默认 1）|
| **优先级** | 数值越高越优先被选中（默认 1）|
| **计费倍率** | 账户级计费倍率，叠加在分组倍率之上 |

### 测试账户可用性

点击账户行的"测试"按钮，系统会发送一个简单请求验证账户是否正常工作：
- ✅ 成功：账户有效，显示响应时间
- ❌ 失败：显示错误信息，自动标记账户错误状态

### 刷新 Token

对于 OAuth 账户，Access Token 会过期，可以：
1. **手动刷新**：点击"刷新"按钮立即刷新 Token
2. **自动刷新**：系统后台服务（TokenRefreshService）定期自动刷新

### 账户统计

点击账户行的"统计"按钮查看：
- 今日使用的 Token 数和费用
- 最近 7 天的使用趋势
- 调度被选中次数

### 批量操作

选中多个账户后可以：
- **批量启用/禁用**
- **批量更新并发数或优先级**
- **批量更新凭证**
- **批量刷新等级**

## 代理管理

访问 `/admin/proxies`

代理用于通过跳板连接 AI API，适用于网络访问受限的环境。

### 添加代理

| 字段 | 说明 |
|------|------|
| **名称** | 代理名称 |
| **协议** | `http` / `https` / `socks5` |
| **主机** | 代理服务器地址（如 `proxy.example.com`）|
| **端口** | 代理端口（如 `8080`）|
| **用户名/密码** | 认证信息（可选）|

### 测试代理

添加代理后点击"测试"按钮，系统会通过该代理访问测试端点，显示延迟和连通性。

### 为账户分配代理

在账户编辑页面的"代理"字段选择代理，保存后该账户的所有请求将通过指定代理发送。

---

## 订阅管理

访问 `/admin/subscriptions`

订阅是将用户与特定分组关联的记录，有时间限制。

### 分配订阅

1. 点击"分配订阅"
2. 搜索并选择用户
3. 选择分组（决定订阅内容）
4. 设置开始时间和结束时间
5. 可添加备注

### 批量分配

上传 CSV 文件批量为多个用户分配订阅：
```csv
user_email,group_id,starts_at,expires_at
user1@example.com,2,2025-01-01,2025-02-01
user2@example.com,2,2025-01-01,2025-02-01
```

### 延期订阅

选中订阅后点击"延期"，可以延长有效期。

### 撤销订阅

点击"撤销"将订阅状态改为 `revoked`，用户立即失去访问权限。

## 公告管理

访问 `/admin/announcements`

### 创建公告

| 字段 | 说明 |
|------|------|
| **标题** | 公告标题 |
| **内容** | 支持 Markdown 格式 |
| **状态** | `draft`（草稿）/ `published`（发布）/ `archived`（归档）|
| **定向条件** | 可以按是否有活跃订阅、余额范围等条件定向推送 |

### 定向推送

可以限制公告只显示给满足条件的用户：
- 有特定订阅类型的用户
- 余额在某个范围的用户
- 所有用户（不设限制）

### 查看阅读状态

点击"阅读统计"查看哪些用户已读、未读。

## 兑换码管理

访问 `/admin/redeem`

### 生成兑换码

| 参数 | 说明 |
|------|------|
| **类型** | `balance`（余额）/ `invitation`（邀请码）/ `concurrency`（并发数）|
| **数量** | 生成多少个 |
| **余额** | 每个码对应的余额（`balance` 类型）|
| **并发** | 每个码对应的并发数（`concurrency` 类型）|
| **有效期** | 兑换码的有效天数（0=永久）|
| **备注** | 内部备注 |

### 导出

点击"导出"生成 CSV 文件，包含所有未使用的兑换码，方便分发。

### 使码过期

对于已分发出去不想继续使用的码，可以手动标记为"过期"。

## 促销码管理

访问 `/admin/promo-codes`

促销码用于注册时的折扣（如 8 折优惠）。

### 创建促销码

| 字段 | 说明 |
|------|------|

## 系统设置

访问 `/admin/settings`

### 站点基础设置

| 设置 | 说明 |
|------|------|
| `site_name` | 站点名称（显示在页面标题、邮件中）|
| `site_logo` | 站点 Logo URL |
| `api_base_url` | API 基础 URL（用于生成完整的 API 地址）|

### 注册和认证策略

| 设置 | 说明 |
|------|------|
| `registration_enabled` | 是否开放公开注册（`true`/`false`）|
| `email_verification_required` | 注册时是否需要邮箱验证 |
| `invitation_code_required` | 注册时是否需要邀请码 |

### SMTP 邮件设置

| 设置 | 说明 |
|------|------|
| `smtp_host` | SMTP 服务器地址 |
| `smtp_port` | SMTP 端口（通常 465/587）|
| `smtp_user` | SMTP 用户名 |
| `smtp_password` | SMTP 密码 |
| `smtp_from` | 发件人地址 |

填写完毕后可以点击"测试 SMTP"验证配置是否正确，再点击"发送测试邮件"验证实际接收。

### 管理员 API Key

可以生成一个特殊的 API Key 用于管理操作（通过 API 而非 UI 操作），支持：
- 获取现有 Key
- 重新生成 Key
- 删除 Key

## 运维监控

访问 `/admin/ops`

这是系统的实时运维中心，提供：

### 实时监控

- **并发概览**：当前整体并发使用情况
- **用户并发**：各用户的并发使用详情
- **账户可用性**：各账户的状态（可用/限流/过载）
- **实时流量**：QPS 实时图表（WebSocket 推送）

### 错误日志

系统自动记录 AI API 的异常请求：
- **错误类型**：4xx 客户端错误、5xx 服务端错误、连接超时等
- **重试功能**：对于可重试的错误，可以手动触发重试
- **解决标记**：标记已处理的错误为"已解决"

### 告警规则

创建告警规则，在以下情况自动触发通知：

| 指标类型 | 示例 |
|---------|------|
| 错误率 | 5 分钟内错误率 > 10% |
| 账户可用性 | 可用账户数 < 3 |
| 并发使用率 | 系统并发使用率 > 80% |
| 响应延迟 | P95 延迟 > 30 秒 |

告警触发后会：
1. 记录告警事件（可在"告警事件"标签查看）
2. 发送邮件通知（需要配置 SMTP）

### 高级设置

可以调整运维相关参数：
- 指标阈值（各类指标的警告/严重级别）
- 错误日志保留时间
- 告警评估间隔

## 使用记录管理

访问 `/admin/usage`

管理员可以查看所有用户的使用记录，支持：

### 高级筛选

- 按用户、API Key、账户、模型筛选
- 按时间范围筛选
- 按费用范围筛选

### 统计汇总

查看指定条件下的汇总统计：总 Token 数、总费用、请求数。

### 数据清理

长期运行后使用记录可能占用大量存储，可以创建清理任务：

1. 点击"清理数据"
2. 设置清理条件：
   - 清理哪个用户的记录（可选，不填=所有用户）
   - 清理哪个时间段之前的记录
3. 点击"执行清理"
4. 在"清理任务"标签跟踪进度

**注意**：清理操作不可撤销，建议先备份数据库。

## 用户属性定义

访问 `/admin/user-attributes`

支持为用户添加自定义属性（如公司名、手机号、用途分类）：

### 创建属性定义

| 字段 | 说明 |
|------|------|
| **名称** | 属性名称（如"公司"）|
| **类型** | `string`（文本）/ `number`（数字）/ `boolean`（开关）/ `select`（单选）|
| **选项** | 仅 `select` 类型需要，定义可选项列表 |
| **必填** | 是否为必填项 |

定义好属性后，在用户详情页可以为每个用户设置具体的属性值。

## 错误透传规则

访问 `/admin/error-passthrough-rules`

控制当上游 AI API 返回特定错误时，系统如何处理：

| 动作 | 说明 |
|------|------|
| `passthrough` | 直接将上游错误透传给客户端 |
| `block` | 屏蔽错误，返回标准错误响应 |

通过匹配规则（HTTP 状态码 + 可选的响应体正则表达式）精确控制。

## 系统管理

访问 `/admin/system`（或通过设置页面的系统区域）

- **查看版本**：当前运行版本、提交哈希、构建时间
- **检查更新**：检查是否有新版本发布
- **执行更新**：在线更新到最新版本
- **回滚**：回退到上一个版本
- **重启服务**：热重启（不停机更新配置）

## 最佳实践

### 分组设计建议

```
推荐分组结构：
├── 免费试用组（低并发、低限额）
│   └── 账户：专用低优先级账户
├── 标准付费组（中等并发）
│   └── 账户：主要账户池
└── 高级专属组（高并发、专属账户）
    └── 账户：高质量专属账户
```

### 账户管理建议

1. **多账户分散风险**：每个分组至少配置 3 个账户，避免单点故障
2. **定期检测可用性**：每周手动或通过告警监控账户健康状态
3. **合理设置并发**：根据账户实际承载能力设置并发数，避免频繁 429
4. **优先级区分**：将稳定高质量账户设置更高优先级

### 监控建议

1. 配置告警规则：账户可用率 < 50% 时立即通知
2. 定期查看错误日志，识别系统性问题
3. 使用 Dashboard 的趋势图监控业务增长，提前扩容账户
