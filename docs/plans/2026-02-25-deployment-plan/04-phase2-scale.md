## 关键变化

### 1. Sub2API 多实例

Sub2API 是无状态的（状态在 PostgreSQL + Redis），可直接水平扩展：

```yaml
# docker-compose.scale.yml
services:
  sub2api-1:
    image: sub2api:latest
    environment:
      - SERVER_PORT=8081
    # ...同一 DB 和 Redis

  sub2api-2:
    image: sub2api:latest
    environment:
      - SERVER_PORT=8082
    # ...同一 DB 和 Redis

  nginx:
    image: nginx:alpine
    ports:
      - "8080:8080"
    # upstream 轮询 8081 / 8082
```

### 2. 阿里云 GA 接入（ICP 备案后）

ICP 备案完成后，成都接入切换到阿里云 GA：

- GA 精品带宽：国内→香港 20-30ms
- 全国三网优化，用户体验一致
- 按量付费：资源包 ¥378/年 + 流量费
- 端到端延迟降至 **165-200ms**

**未备案替代**：继续使用成都 Nginx 直连香港 BGP 精品线路。

### 3. 数据库升级

**选项 A：托管 RDS（推荐）**
- 阿里云 RDS PostgreSQL 香港（基础版 2核4G ¥300/月）
- 自动备份、监控、故障转移
- 省去 DBA 运维

**选项 B：自建主从**
- 香港主 + 成都从（异步复制，灾备）
- 需自行维护
