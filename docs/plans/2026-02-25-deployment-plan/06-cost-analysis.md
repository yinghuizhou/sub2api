### Astrill VPN 成本优化

Astrill Private IP 是按月计费 $5/IP。优化策略：

1. **共享 IP 模式**：不买 Private IP，使用 Astrill 共享节点
   - 成本：仅 Astrill 月费 ~$10
   - 风险：IP 被其他用户"污染"，更容易被封
   - 适合：Phase 0 验证阶段

2. **混合模式（推荐）**：核心节点用 Private IP，备用节点用共享
   - 3 个 Private IP（us-east × 2 + us-west × 1）= $15/月
   - 其余共享节点作为降级出口
   - 成本降低 50% 同时保留核心稳定性

3. **规模折扣**：10+ Private IP 可联系 Astrill 商务谈折扣

### 盈亏平衡点

```
月固定成本（Phase 0）= ¥90
API 可变成本率 = 74%
毛利率 = 26%

盈亏平衡月收入 = ¥90 / 0.26 = ¥346
→ 约 2 个活跃付费用户（ARPU ¥200）

Phase 1 盈亏平衡 = ¥500 / 0.26 = ¥1,923
→ 约 10 个活跃付费用户
```

**极低的盈亏平衡点**——核心成本几乎全部是可变的 API 成本。

## 关键风险因素

### 成本风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| Astrill 涨价/下线 | 需迁移代理方案 | 备用：自建 WireGuard VPN |
| API 提供商涨价 | 利润率下降 | 及时调整用户端定价 |
| 账号被封 | 直接损失 + 服务中断 | 账号池冗余 + 快速补充 |
| 汇率波动 | 成本不可预测 | 以美元为基础定价 |

### 收入风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 用户 ARPU 低于预期 | 盈利困难 | 优先发展企业客户 |
| 价格战 | 利润率压缩 | 差异化（稳定性、速度） |
| 国产模型追赶 | 需求下降 | 接入国产模型做混合服务 |
| 监管收紧 | 业务中断 | 备案合规 + 应急预案 |
