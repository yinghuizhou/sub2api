# 零停机滚动部署指南

## 问题背景

在使用 `docker compose up -d` 部署 HA 配置时，会同时重启所有 3 个实例，导致：
- **503 错误**：所有实例同时停止，Nginx 无可用后端
- **停机时间**：约 30-60 秒（取决于启动速度）
- **用户体验差**：正在进行的请求被中断

## 解决方案总结

1. **滚动部署脚本**：逐个更新实例，确保 2/3 实例始终在线
2. **改进 Nginx 配置**：更快的故障检测和恢复（max_fails=2, fail_timeout=10s）
3. **优化健康检查**：缩短检查间隔和启动期

## 使用滚动部署脚本

```bash
./scripts/rolling-deploy-hk.sh
```

**特性**：
- ✅ 零停机部署
- ✅ 自动健康检查
- ✅ 失败自动回滚
- ✅ 详细日志输出

详细文档请查看脚本内的注释。
